## About

This portfolio highlights my projects, experience, skills, and achievements as a Computer Science student and software engineer. The redesign prioritized a clean, dark aesthetic with fluid animations and a fully componentized architecture.

## Tech Stack

- **React 19** — component-based UI
- **Vite** — fast development and build tooling
- **Tailwind CSS** — utility-first styling
- **Framer Motion** — page and scroll animations
- **Embla Carousel** — awards/carousel section
- **Radix UI** — accessible UI primitives
- **React Router DOM** — client-side routing
- **Lucide React / React Icons** — iconography

## Sections

- **Hero** — introduction with animated text loop
- **About** — background and interests
- **Projects** — selected work with tags, links, and collaborator credits
- **Experience** — work history
- **Skills** — technical skill overview
- **Awards** — achievements displayed in a carousel
- **Contact** — email and LinkedIn
